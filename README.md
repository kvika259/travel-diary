# 🌍 Дневник путешествий

Веб-приложение для ведения дневника путешествий с авторизацией. Каталог стран, городов и достопримечательностей с возможностью отмечать посещённые места, создавать воспоминания с фото и отслеживать свой прогресс на карте мира.

## Концепция

Приложение — это **каталог мира**, по которому можно путешествовать виртуально и отмечать посещённые места. Воспоминания (поездки) — отдельный слой: записи с описанием и фото, привязанные к городу или стране. Отметка «Посетил» не зависит от наличия воспоминаний.

Данные хранятся на сервере (MongoDB), каждый пользователь имеет свой профиль и свои отметки/воспоминания. Все данные изолированы по пользователям.

## Авторизация

- Регистрация (username, email, пароль)
- Вход (email, пароль)
- JWT-токен сохраняется в localStorage
- После входа/регистрации — редирект на главную (`/`)
- Все экраны кроме логина/регистрации защищены (редирект на `/login`)
- Кнопка «Выйти» в шапке

## Основной функционал

### Каталог стран
- ~250 стран с русскими названиями и флагами-эмодзи (из встроенного датасета)
- Поиск по названию
- Прогресс-бар посещения для каждой страны
- Добавление собственных стран (с нормализацией имени — первая буква заглавная)

### Города
- Столицы и крупные города (из встроенного датасета + из seed)
- Отметка «✔️ Посетил» для каждого города
- Счётчик посещённых достопримечательностей и воспоминаний
- Добавление собственных городов (с проверкой дубликатов и нормализацией имени)
- Список посещённых городов под картой страны (сворачиваемый)

### Достопримечательности
- 100+ предзаполненных достопримечательностей
- Отметка «✔️ Посетил» для каждой
- Добавление собственных (с проверкой дубликатов и нормализацией имени)
- **Каскад авто-отметки**: при отметке достопримечательности автоматически отмечается город, а при отметке города — страна

### Воспоминания (поездки)
- Записи, привязанные к конкретному городу или стране
- Заголовок, описание, даты поездки
- Прикрепление нескольких фотографий (при создании и после)
- Просмотр, редактирование, удаление
- Несколько воспоминаний на один город

### Мои путешествия
- Дерево воспоминаний: **Страна → Город → Воспоминания**
- Сворачиваемые/разворачиваемые секции
- Поиск по тексту заметок, названиям городов и стран
- Кнопка создания нового воспоминания

### Создание воспоминания
- Выбор страны и города через **SearchableSelect** — выпадающий список с поиском по началу названия
- Возможность создать новый город прямо из выпадающего списка, если он не найден
- Защита от дубликатов (case-insensitive)
- Нормализация имени (Title Case с поддержкой кириллицы)
- Выбор фото при создании поездки (загружаются после создания)

### Карта
- Интерактивная карта на базе Leaflet + OpenStreetMap
- Общая карта мира с маркерами только посещённых городов
- Карта внутри каждой страны (только посещённые города)
- 🟢 Зелёные маркеры — посещённые города
- Клик по маркеру → переход к экрану города
- Под общей картой — список посещённых стран со свернутыми списками городов (двухуровневое сворачивание)

### Поиск и фильтрация
- Поиск по странам на главной странице
- Поиск по воспоминаниям в разделе «Мои путешествия»
- Фильтрация городов по стране (`?countryId=`) и по статусу посещения (`?visited=true`)

## Навигация

Нижняя панель:
- 🌍 **Каталог** — страны → города → достопримечательности
- 📚 **Путешествия** — все воспоминания (дерево)
- 🗺️ **Карта** — карта мира + список посещённых стран
- ⚙️ **Настройки** — аккаунт

Шапка: название приложения + имя пользователя + кнопка «Выйти»

## Стек технологий

- **React 19** + **Vite**
- **React Router** — маршрутизация + защита роутов
- **AuthContext** — управление JWT-токеном, login/register/logout, `apiFetch` для авторизованных запросов
- **TravelContext** — все данные через API (страны, города, достопримечательности, поездки, фото)
- **Leaflet + react-leaflet** — интерактивные карты (OpenStreetMap)
- **CSS Modules** — стилизация
- **ErrorBoundary** — отлов ошибок рендера с показом стека

## Ключевые механизмы

### Изоляция данных по пользователям
Все отметки «Посетил», поездки и фото привязаны к `userId`. Каждый пользователь видит только свои данные.

### Каскад авто-отметки
- Отметка достопримечательности → автоматически отмечается город
- Отметка города → автоматически отмечается страна
- Реализовано на бэкенде (создание `VisitedCity` и `VisitedCountry` записей)

### Оптимистичные обновления
При тогле `visited` фронтенд сразу обновляет локальный стейт, а `refreshCountries`/`refreshCities` сохраняют локальные `visited`-флаги при слиянии с серверными данными.

### Фото с авторизацией
Загрузка фото через `multipart/form-data` с заголовком `Authorization`. Отображение через `<img src="...?token=...">` — бэкенд поддерживает `?token=` query-параметр как fallback к `Authorization` header.

### SearchableSelect
Кастомный combobox с поиском по началу названия, навигацией с клавиатуры (↑↓ + Enter) и кнопкой создания нового элемента, если не найден.
